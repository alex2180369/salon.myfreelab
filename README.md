# Maison de beauté — учебное цифровое меню

Учебное локальное веб-приложение: лендинг на HTML/CSS/JavaScript, локальный Node.js сервер и SQLite. Для приёма заявок запускайте `node server.js`, затем открывайте `http://127.0.0.1:4173/`. Панель администратора: `http://127.0.0.1:4173/admin`.

## Демонстрационный каталог

В `index.html`, в объекте `menuData`, находятся примеры каталога и правил:

- Напитки: американо 150 ₽, капучино 220 ₽, латте 240 ₽, чёрный/зелёный чай 150 ₽, травяной чай 180 ₽, вода без газа — комплимент, вода с газом 100 ₽.
- Услуги: дополнительный уход 350 ₽/15 минут, экспресс-массаж рук 500 ₽/10 минут, уходовая процедура 900 ₽/30 минут. Время и доступность подтверждает администратор.
- Товары: крем для рук 690 ₽, масло для кутикулы 490 ₽, шампунь 990 ₽. В учебных данных наличие отмечено как демонстрационное.
- Чаевые добровольны, варианты 100/300/500 ₽, своя сумма от 50 ₽. Онлайн-оплата недоступна; чаевые лишь добавляются к локальному черновику запроса.

Все цены, составы, объёмы и сведения о наличии придуманы для учебного проекта и показаны в интерфейсе как демонстрационные. Валюта макета — ₽. Это не реальные предложения салона.

## Готовность функций и ограничения

- Работают фильтры напитков, карточки услуг/товаров, корзина, количество, удаление, очистка, комментарии, расчёт демонстрационных цен и валидация чаевых.
- Заявки принимает `server.js` и записывает в `data/requests.sqlite`. Панель администратора показывает список заявок, позволяет менять статус и показывает прошлые заявки клиента по номеру телефона.
- Для уведомлений в Telegram создайте бота через `@BotFather`, скопируйте `.env.example` в `.env` и укажите токен. Напишите боту `/start`, выполните `node telegram-chat-id.js`, внесите найденный личный chat ID в `.env` и перезапустите сервер. Без этих значений заявка всё равно сохраняется в SQLite и видна в панели. Токен не указывайте в браузерном коде.
- Медиатека содержит четыре категории с сообщением «Подборка скоро появится»; внешних фиктивных ссылок нет.
- Онлайн-оплата и интеграция с YCLIENTS не подключены. Telegram-уведомление включается только при настройке локальных секретов. Номер телефона в учебной версии используется как ключ поиска истории заказов.
- Фотографии меню лежат в `assets/photos/` в оптимизированном формате WebP: для каждого напитка и товара назначено отдельное изображение по названию карточки, без внешнего фотохостинга. Разделы в быстром меню открываются обычными якорными ссылками; каталог, фильтры, добавление и редактирование запроса работают на странице.

## HTTPS, публикация и QR-код

Подготовленный адрес: [https://unique-pastelito-f54dff.netlify.app/](https://unique-pastelito-f54dff.netlify.app/). Адрес открылся по HTTPS и показывает обновлённые учебные данные при проверке 18 октября 2026 года. QR-код в `qr-menu.png` и `qr-menu.svg` содержит именно этот URL; PNG декодирован обратно для проверки.

Файлы `qr-menu.png` и `qr-menu.svg` ведут на опубликованный адрес выше и относятся к отдельной опубликованной копии. Локальная версия с приёмом заявок работает по адресу `http://127.0.0.1:4173/` на компьютере администратора; QR-код на неё не используется.

Нужен Node.js 22.13+ (проект проверялся на Node 24) с встроенным модулем SQLite. Сборка и npm-зависимости не требуются. Запустите `node server.js` из папки проекта; остановка — Ctrl+C. Встроенный favicon и title лендинга уже заданы.

## Проверено

- `node tests/menu-smoke.cjs` — smoke-сценарии каталога, фильтров, корзины, комментариев и чаевых.
- `node --check server.js` и `node --check integration.js`.
- Публичный HTTPS URL доступен и показывает обновлённые напитки, услуги, товары, чаевые и медиатеку. Перед реальным запуском отдельно проверьте отображение на физических смартфонах и Samsung Galaxy Tab A9.

## Перед полноценной эксплуатацией

Заменить учебные данные и изображения на утверждённые салоном. Для реальной отправки запросов настроить сервер, уникальный ID от сервера, защиту от повторов и уведомление администратора. Для YCLIENTS отдельно проверить разрешённые операции и доступы; секреты хранить только на сервере. Подключать платёжного провайдера только при необходимости и не обозначать чаевые оплаченными до фактического подтверждения платежа.
